Test wording variants on any website

Microcopy Lab replaces titles, labels, buttons, placeholders and tooltips according to a simple spreadsheet — so you can test how people read your product, without touching code.

Install View source

Free and open source · Chrome & Edge · English and German interface

How it works

Four steps, and from then on you only edit the spreadsheet.

1

Enable a website

Open your site — web apps behind a login work too — and enable Microcopy Lab for it. It runs nowhere else.

2

Collect the texts

Click through the pages. Every visible text, placeholder and tooltip is collected automatically.

3

Write your variants

Export to Excel or CSV and add a column per variant. An empty cell keeps the original.

4

Switch and test

Import the file or link a Google Sheet, then switch variants live — no reload, no deployment.

What it can do

Built for real products, not demo pages.

Works in modern web apps

Texts that load later or change on the fly are replaced too — React, Angular, Vue and anything else.

Unlimited variants

Add as many columns as you like and switch between them from the toolbar popup.

Rules per page

The same word can read differently on two screens. IDs in addresses are matched automatically.

Placeholders

“{n} items” becomes “{n} products” — the number stays whatever the page shows.

Checked before it goes live

Every import reports duplicates, broken placeholders and entries never seen on any page.

Test links

Add ?_variant=B to a URL and the session opens in that variant straight away.

See it in action

The same screen, two wordings — and a highlight mode that shows what the table still misses.

The table

Any spreadsheet with these columns works. English and German headers are both understood.

*placeholderSearch projectsFind a project …Search

page: * everywhere, a path for one screen, /settings/* including sub-pages. type: text, placeholder, tooltip or aria. Every other column becomes a variant.

Your data stays with you

  • No account, no server, no analytics, no tracking.
  • Tables, settings and collected texts are stored only in your own browser.
  • The extension runs only on websites you enable yourself, one at a time.
  • The one network request it ever makes is downloading a table from an address you entered.
